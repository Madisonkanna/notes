1.2 Hardware

The term hardware refers to all of the physical devices, or components, that a computer is made of. A computer is not one single device, but a system of devices that all work together. A typical computer consists of the following major components:

- The central processing unit (CPU). 
- Main memory
- Secondary storages devices
- Output devices
